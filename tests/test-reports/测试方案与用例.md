## 1. 测试概述

### 1.1 应用简介
「星际控制台」是一个**多框架组件演示与数据看板门户**，规模约 48 个路由页面，涵盖：
- **数据看板**：深空 `/astro`、地球 `/geo`、海洋 `/ocean`、时空档案 `/timeline`（实时拉取 NOAA/SWPC/USGS/NDBC 等公开数据源）
- **AI 能力**：ChatBot 流式对话 `/chatbot`、对话分享 `/share`、语音助手 `/voice`、AI Agent `/agent`
- **组件工坊**：Kit `/kit`、Studio `/studio`、Templates `/templates`、Utils `/utils`
- **微前端**：qiankun 融合 Vue(`/micro-vue`) / Angular(`/micro-angular`) 子应用
- **多语言**：`useI18n()` 驱动 10 语种（zh-CN / zh-TW / en / ja / ko / de / fr / th / mn / bo）即时切换

### 1.2 本轮测试目标（重点）
1. **i18n 迁移回归**（最高优先）：项目刚完成三块看板 + ChatBot/Studio 的国际化迁移，须验证语言切换全局生效、无漏键、无运行时崩溃。
2. **全路由运行时健康**：48 个路由在真实浏览器中无 console error、无未捕获异常、均渲染出真实内容。
3. **核心用户流程**：登录守卫、导航、语言切换、数据看板数据拉取。

### 1.3 测试原则（端测测信条）
- **测试金字塔**：单元(70%) + 集成(20%) + E2E(10%)，不倒金字塔。
- **关键路径 100% 覆盖**：登录、导航、语言切换、数据看板加载属关键路径，必须全覆盖。
- **稳定胜过速度**：flaky 测试比没有测试更糟——数据看板依赖外网，单测与冒烟必须可离线/可重试。
- **可访问性是必测项**，不是 nice-to-have。
- 用建设性语言汇报，目标是「让团队敢发布」。

## 3. 测试策略与分层

采用**分层测试金字塔**，每层职责、工具、入口、频率如下：

| 层 | 类型 | 工具/入口 | 覆盖 | 频率 | 离线 |
|---|---|---|---|---|---|
| **L1** | 单元/纯函数 | `npm test`（`scripts/run-tests.mjs`，383 断言） | i18n 键结构、glossary、relations、utils、chat-stream 协议 | 每次提交 | ✅ |
| **L2** | SSR 冒烟 | `npm run test:ssr` | 组件树服务端渲染不炸、内容断言 | 每次提交 | ✅ |
| **L3** | 浏览器运行时冒烟 | `npm run test:browser`（CDP headless，48 路由） | 每路由无 console error / 未捕获异常 + 真实内容 | 每日/发版 | ⚠️ 需 dev |
| **L4** | 功能 E2E | `python tests/test_pages.py`（Playwright） | 逐页文本+选择器断言、代表性交互 | 发版 | ⚠️ 需 dev |
| **L5** | 数据看板 live 冒烟 | `npm run test:astro`（73）`npm run test:earth`（63） | 看板数据管道、分档、warmup | 每日 | ❌ 外网 |
| **L6** | 微前端冒烟 | `npm run test:qiankun` | qiankun 挂载/通信 | 发版 | ⚠️ 需子应用 |
| **L7** | i18n 覆盖率 | `npm run i18n:scan` | 剩余硬编码中文清单 | 迁移期每次 | ✅ |
| **L8** | 可访问性 / 视觉 | axe-core + Playwright 截图（**建议新增**，见 §10） | WCAG 2.1 AA、UI 视觉回归 | 发版 | ⚠️ |

> 设计取舍：L3 用 Node 内置 WebSocket 直连 CDP，**零新依赖**，且从 `App.jsx` 自动解析路由（新增页面无需改脚本）；L5 依赖外网，仅每日跑，避免阻塞提交。

## 4. 测试环境与前置条件

### 4.1 环境
- Node ≥ 22.12（`engines` 约束）；本机 `node` 22.22.2。
- macOS + Google Chrome（`/Applications/Google Chrome.app`，CDP 冒烟必需）。
- Python 3 + `pip install -r tests/requirements.txt` + `playwright install chromium`（仅 L4 需要）。

### 4.2 关键命令约定（务必遵守）
- **所有 build/dev 必须剥离 `NODE_OPTIONS`**：`env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 <cmd>`，否则长输出 EPIPE 断管 / 清产物被护栏拦。
- **i18n 单测真入口是 `npm test`**，不是 `node --test tests/unit/i18n.test.mjs`（后者对自定义 harness 格式只报「空测试 ok」= 假绿）。

### 4.3 登录态（测试数据核心）
路由由 `RequireAuth` 保护，未登录会跳 `/login`。自动化需注入会话：
```
localStorage.setItem('starfleet.session', JSON.stringify({ name: 'smoke', loginAt: Date.now() }))
```
（`STORAGE_KEY = 'starfleet.session'`，见 `src/contexts/AuthContext.js`）

### 4.4 端口冲突处理
默认 dev 端口 5173。若被占用，Vite 自动顺延（5174…）。冒烟脚本用 `BASE_URL=http://localhost:<port>` 指定；CDP 端口用 `CDP_PORT` 覆盖避免多实例互踩。

## 8. 测试执行步骤（SOP）

### 8.1 每日/提交前（离线，最快反馈）
```bash
# 1) 单元 + i18n 一致性（真入口）
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 npm test      # 期望 383/383

# 2) SSR 冒烟
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run test:ssr
```

### 8.2 发版前（需 dev server）
```bash
# 3) 起 dev（另开终端，或后台）
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run dev
#    记录实际端口（默认 5173，占用则顺延）

# 4) 浏览器运行时冒烟（自动解析 48 路由 + 注入登录态）
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 BASE_URL=http://localhost:5173 npm run test:browser

# 5) 功能 E2E（首次需装依赖）
pip install -r tests/requirements.txt && playwright install chromium
BASE_URL=http://localhost:5173 python tests/test_pages.py

# 6) 微前端（需先 npm run dev:all 起 vue/angular）
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run test:qiankun
```

### 8.3 数据看板每日巡检（外网）
```bash
env -u NODE_OPTIONS CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run test:astro   # 73 项，脚本内含 warmup
```

### 8.4 i18n 迁移期专用

### 8.5 失败分级与处理
| 级别 | 现象 | 处理 |
|---|---|---|

## 10. 风险与改进建议

### 10.1 风险
| 风险 | 影响 | 缓解 |
|---|---|---|
| i18n 覆盖率仅 ~部分 | 非默认语种下大量页面仍中文，违背「全站跟随语言」目标 | 按 `i18n:scan` 目录聚合逐模块推进；词典多语言化单独立项 |
| 数据看板依赖外网 | L5 偶发红，可能掩蔽真实回归 | 外网层仅每日跑 + warmup；UI 层用 mock 隔离 |
| 无 A11y/视觉回归 | 暗色对比度、语言切换后布局塌陷难以及时发现 | 见 10.2 |
| `node --test` 假绿 | 误判 i18n 通过 | 固化到 `npm test`，文档与脚本注释双提示 |

### 10.2 改进建议（按性价比排序）
1. **补 i18n E2E 用例**（P0）：在 `test_pages.py` 增加「切 en 后已迁移页无中文/无键名」断言，把本轮迁移成果钉进回归。
2. **引入可访问性门禁**（P1）：CDP 冒烟里注入 axe-core，对关键页跑 WCAG AA；语言切换后复测布局。
3. **视觉回归基线**（P1）：对 3 看板 + ChatBot + Studio 在 zh-CN/en 各存一张基线截图，Playwright 比对。
4. **看板 UI 离线化**（P2）：L5 外网逻辑与 UI 解耦，UI 冒烟改喂 fixture，摆脱网络抖动。
5. **词典多语言化**（既定延后项）：`glossary.js`/`relations.js` 改 `{lang}` 结构，同步改 2 个单测 + 消费者，一次性补齐 803 行。
