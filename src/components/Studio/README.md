# Studio · 组件工坊

从本地 `Front-End` 目录下 80+ 存量前端项目里，**筛选、去业务化、零依赖重写**而成的可复用组件集合。本目录下的所有组件：

- 不认识任何业务字段，只接收通用 props / schema；
- 不含任何内部域名、接口路径、token、存储键、品牌、组织/角色名；
- 演示数据全部为中性虚构占位（资源 / 节点 / 配置 / 区域等），与原始项目无关；
- 样式统一走 `--c-*` 主题变量并带 fallback，明暗主题均可工作；
- 可直接整目录复制到其他 React 19 + antd 5 项目使用。

> 去敏说明：本次抽取前，已先把本项目此前从 `旧移动端项目` / `旧平板端项目` 搬来的 Kit 模块里的内部项目代号、内网域名、品牌与医疗业务数据全部替换；本 Studio 模块从零就以中性占位编写，零敏感信息。

## 选型台账（调研结论摘要）

对 80+ 个存量项目按「A 直接移植 / B 重写移植 / C 借鉴思路 / D 不移植」分级，结论要点：

- **D 不移植（约 15 个）**：`ant-design-pro`、`element`、`element-plus`、`react-admin*`、`react-master`、`react-xs-admin`、`ueditor`、`flukit`（Flutter，非 Web）、`ThinkPHP5` 等 —— 纯上游开源模板，无自研定制价值。
- **C 借鉴思路（Vue / 原生壳 / 后端项目）**：若干 Vue 后台模板、移动端 Android 壳项目、iOS 原生壳项目、Flutter 项目、React 前端中台、供应链安全检测工具等 —— 其交互/算法/可视化思路被本模块抽取重写，但源码不照搬（技术栈不兼容或含大量业务耦合）。
- **B 重写移植（已落地）**：本目录 24 个组件，均按 React 19 不兼容项（findDOMNode、老拖拽库、老图表库、antd3/dva/ReactDOM.render）做了零依赖重写。
- **A 直接移植（此前已完成）**：签名板、下拉刷新、无限滚动、悬浮球、零依赖拖拽排序等已在 `src/components/Kit` 落地，本模块不再重复。

### 刻意未搬的清单
- antd 5 已内置的能力（Modal / Drawer / 基础表单控件 / 表格虚拟滚动等）；
- 强业务耦合的页面逻辑（审批流、工单状态机、微信/钉钉 bridge 调用、组织层级契约）；
- 已在 Kit 模块搬过的同名能力；
- 非 Web 原生实现（Swift / Flutter / Android Java）——仅取其思路。

## 迁移基线（React 19 兼容要点）

1. **ref 不混进自定义 hook 返回对象**：`useChart` 把实例通过 `onReady` 回调交回调用方，而非返回 ref。
2. **不在 effect 里同步 setState**：懒加载/惰性触发优于挂载即加载。
3. **零依赖重写老库**：Canvas 2D 替代 `react-canvas-draw`、Pointer Events 替代 `react-sortable-hoc`、ECharts6 替代 AntV G2。
4. **滚动/动画走纯视觉层**：位移/溢出标记写进 DOM 属性或 CSS 变量，不进 React state，避免重渲染。
