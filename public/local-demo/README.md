# 本地媒体中心 · 演示目录

这是一个**演示文件夹**：用页面上的「路径直填」把目录指到这里，就能一次看到全部四类分区。

| 分区 | 本目录对应文件 | 说明 |
| --- | --- | --- |
| 🐍 Python 效果 | `hello_effect.py` | 点「运行」由后端 `python3` 执行，生成 `effect_output.svg` 作为产物展示 |
| 📄 文档（文本） | `notes.txt`、`README.md` | 经 `/api/read-text` 内联查看 |
| 🖼️ 图片 | （运行脚本后生成） | `effect_output.svg` 生成后也会出现在图片网格里 |
| 🎬 视频 | （无） | 放入 mp4/webm/mov/mkv 即出现轮播 |

> 目录选择器（选择文件夹按钮）受浏览器安全限制拿不到绝对路径，只能视频轮播；
> 需要 **Python 运行 / 文档读取** 请用上方「路径直填」填入本目录的绝对路径
> （在本目录里执行 `pwd` 即可取到，形如 `<项目根目录>/public/local-demo`）。
